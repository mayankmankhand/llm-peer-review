# Reading Budget

Keep reading bounded so a review stays fast and on point:

- Open at most the changed files plus ~3 files they directly reference. Resist following the dependency graph further.
- For a file over 400 lines, read the changed sections plus ~50 surrounding lines for context, not the whole file.
- Stop reading once the change is judgeable - more reading rarely changes the finding.
- Keep what you write in chat under ~800 words, so the summary reads at a glance: findings, not narration. The report file carries every finding in full (`report-format.md`).
