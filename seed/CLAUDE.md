## Toolkit

This project uses the LLM Peer Review toolkit, installed as the `tk` Claude Code plugin. Its commands and skills come from the plugin, not from files in this project, so they are typed with the `tk:` prefix: `/tk:explore` to start a piece of work, `/tk:review` for a unified auto-detected review, or `/tk:review-code`, `/tk:review-ux`, and so on for a focused one. The rules for how Claude works with you in this project are in `.claude/rules/toolkit.md`. Commands and skills you write yourself under `.claude/` sit alongside the plugin's and are typed without the prefix.
