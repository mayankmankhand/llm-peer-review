# Notebook

A small web app for writing short notes and finding them again later. Everything stays on your computer in one file, `data/notes.json`.

## Getting started

1. Install Node.js 18 or newer.
2. In this folder, run `npm run dev`.
3. Open http://localhost:3000 in your browser and write your first note.

## Where your notes live

Each note is saved to `data/notes.json` as soon as you press Add. Copy that file to back up your notes.
