### R1 [docs-drift] - WARN - CHANGELOG.md:11

**File:** `CHANGELOG.md` line 11

> "Install command for runtime deps is now `cd .claude/scripts && npm install`"

The install command documented in the v4.3.0 changelog entry differs from the canonical form used everywhere else in the repo.

| File | Command shown |
|---|---|
| CHANGELOG.md (v4.3.0) | `cd .claude/scripts && npm install` |
| README.md | `npm install --prefix .claude/scripts` |
| SETUP.md | `npm install --prefix .claude/scripts` |
| AGENT-SETUP.md | `npm install --prefix .claude/scripts` |
| setup.sh output | `npm install --prefix .claude/scripts` |
| setup.ps1 output | `npm install --prefix .claude\scripts` |
| CHANGELOG.md (migration note, line 21) | `npm install --prefix .claude/scripts` |

The CHANGELOG line even says "README.md, SETUP.md, AGENT-SETUP.md...have all been updated" - implying those docs reflect the authoritative form. Both commands work identically, but the inconsistency in the most user-visible "what changed" document causes confusion.

- **Why:** Users reading the changelog to understand v4.3.0 get a different command from every other source. The canonical `--prefix` form is safer because it does not change the working directory, which matters if the user is scripting or chaining commands.
- **Fix direction:** Change the CHANGELOG.md line 11 occurrence to `npm install --prefix .claude/scripts` to match all other docs.
- **Status:** Fixed in this run.

### R2 [code] - SUGGEST - .gitattributes

**File:** `.gitattributes`

```
scripts/** text eol=lf
```

The `scripts/**` glob covers `scripts/setup/*.sh|*.ps1`. The runtime scripts moved to `.claude/scripts/` in v4.3.0, but `.gitattributes` was not updated to add a matching rule for `.claude/scripts/**`.

- **Why:** JavaScript files are not bash-sensitive to CRLF the way shell scripts are, so this is low risk. However, if `.claude/scripts/*.js` is cloned on Windows with `text=auto` and git decides to use CRLF, the `#!/usr/bin/env node` shebang and internal string splits still work fine under Node. The risk is minimal.
- **Fix direction:** Add `.claude/scripts/** text eol=lf` (or just `*.js text eol=lf` for global coverage) to `.gitattributes`. Exercise caution - changing gitattributes can renormalize existing checkouts.
- **Status:** Deferred. Low risk for JS; potential for unintended renormalization side effects. No action taken.
