# artifacts/

Cycle-bound HTML output generated by toolkit commands. The `html/` subdirectory holds HTML companion files for reviews, plan renders, debate summaries, and similar outputs. The `html/` subdirectory and its contents are gitignored; each user generates their own.

This README is checked in so the directory is discoverable in fresh clones.

See `.claude/rules/html-outputs.md` for the full HTML output policy.
